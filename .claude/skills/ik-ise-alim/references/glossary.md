# Terim Sözlüğü (Türkçe iş terimi → kod adı)

Kodda her zaman sağ sütundaki adı kullan. Arayüzde soldaki Türkçe terimi kullan. Yeni bir terim gerekirse buraya ekle ve tutarlı kal.

| Türkçe (arayüz) | Kod (İngilizce) |
| --- | --- |
| Aday | `Candidate` |
| Aday belgesi / CV | `CandidateDocument` |
| Genel havuz / Yetenek havuzu | `TalentPool` (`Candidate.InTalentPool`) |
| IK Ön Görüşme Formu | `Screening` |
| Görüşme şekli | `ScreeningChannel` (`Phone`, `InPerson`, `Teams`) |
| Eğitim | `Education` |
| Yabancı dil | `LanguageSkill` |
| Beşeri yetkinlik | `SoftSkills` |
| Teknik yetkinlik | `TechnicalSkills` |
| Deneyim özeti | `ExperienceSummary` |
| Motivasyon | `Motivation` |
| Toplam iş deneyimi | `TotalExperienceYears` |
| Toplam alan deneyimi | `FieldExperienceYears` |
| Ücret beklentisi | `ExpectedSalary` |
| İhbar süresi | `NoticePeriodWeeks` |
| İK yorumu | `HrComment` |
| Kara liste | `Blacklist` / `BlacklistEntry` |
| Mükerrer aday | `DuplicateCandidate` |
| Kaynak (aday kaynağı) | `CandidateSource` |
| Kadro talebi | `HiringRequest` |
| Onay akışı / adımı | `ApprovalFlow` / `ApprovalStep` |
| Seviye | `Level` |
| Birim / Departman | `Department` |
| Pozisyon | `Position` |
| Doluluk | `FilledCount` |
| Süreç (adayın bir pozisyondaki süreci) | `Application` |
| Süreç hattı / aşama | `Pipeline` / `PipelineStage` |
| Süreç şablonu | `PipelineTemplate` |
| Red nedeni | `RejectionReason` |
| Aday çekildi | `Withdrawn` |
| CV önerme / değerlendirme | `CvReview` |
| Mülakat | `Interview` |
| Mülakatçı | `Interviewer` |
| Mülakat tipi | `InterviewType` |
| Aday gelmedi | `NoShow` |
| Müsaitlik | `Availability` |
| Toplantı odası | `Room` |
| Soru bankası / soru | `Question` |
| Yetkinlik | `Competency` |
| Değerlendirme ipuçları | `Guidance` |
| Mülakat şablonu | `InterviewTemplate` |
| Değerlendirme formu (puan kartı) | `Scorecard` / `ScorecardItem` |
| Genel karar (Kesinlikle Al … Kesinlikle Alma) | `Recommendation` (`StrongHire`, `Hire`, `Undecided`, `NoHire`, `StrongNoHire`) |
| Değerlendirme toplantısı | `Debrief` |
| Teklif / Karşı teklif | `Offer` / `CounterOffer` |
| İşe alındı | `Hired` |
| Oryantasyon / işe giriş | `Onboarding` |
| Onboarding görevi / sorumlu birim | `OnboardingTask` / `ResponsibleUnit` |
| Referans çağrısı (çalışan referans programı) | `ReferralCampaign` |
| Aday önerisi (çalışandan) | `Referral` |
| Öneren çalışan | `Referrer` |
| Prim | `Bonus` |
| Referans kontrolü | `ReferenceCheck` / `ReferenceContact` |
| Case / ödev | `CaseAssignment` / `CaseTemplate` |
| Zaman çizelgesi | `Timeline` / `TimelineEntry` |
| Bildirim | `Notification` |
| Sözlük | `Dictionary` |
| İşlem kaydı | `AuditLog` / `AccessLog` |
